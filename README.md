# CodeFolio

An Angular project with ASP.NET

## Features
- Login (with JWT token)
- Homepage  
- Weather data  
- Movies & Favourite  
- News & Bookmark
- Contact Us
- Mini ERP System
- AI PDF Analyzer
- Face Analyzer with AI(TensorFlow)
- Document AI Text Scanner
## Tech Stack
- Angular  
- ASP.NET  
- MySQL
